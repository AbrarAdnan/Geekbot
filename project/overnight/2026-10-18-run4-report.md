### S3.5 outline (written before building)
**The idea.** Three small things in the answer path, each plain code with tests; no new model call. (1) **Abstain by refusal (D-082, option B):** the system prompt gets one exact refusal sentence ("I could not find it in the documents."), the graph recognises it (`is_refusal`) and sets `abstained` in the state; the "nothing found" stop-gap uses the same sentence; no score threshold anywhere. Abstention is then *measured*: `geekbot eval abstention` runs the 100 golden questions through the real graph and counts how many of the 20 unanswerable ones were refused and how many answerable ones were refused wrongly (live, on the proto model `gemma3:4b`, named in the result). (2) **`cite_check` (post-stream):** for each sentence that carries `[n]` marks, the reranker's cross-encoder scores the sentence against source n's text; a score under `cite_weak_below` (default -3.0, **an unmeasured starting point**) marks the citation *weak*. Report only: the answer is not changed, the flag is shown (terminal now, UI later). It runs after the text has been streamed, so it adds nothing to time to first token. (3) **`sanitize.py` (G3, the ✍️ piece: the streaming-safe image stripper):** markdown images (inline, reference style, HTML `<img>`) are removed; links whose URL is not one that appears in the sources shown to the model are reduced to their text; link-reference definitions to such URLs are dropped; fragment links (`#x`) stay. It works on a stream: a small parser holds back only the text that may still turn into a construct (`![`, `[`, `<`), releases the rest at once, and if a construct stays open past a cap it escapes the opener so a later `](url)` cannot complete it. The same function runs on the streamed pieces, on the final answer and on **CSV replies** (a cell can contain `![x](http://...)`).
**Wiring:** `generate` streams through `StreamSanitizer` (events carry safe text only); graph `generate → validate_citations → cite_check → sanitize → remember`; `csv_ask → sanitize → remember`; `no_context → remember` (its sentence is the application's own).
**State/context/config:** new keys `abstained`, `citation_checks`, `removed_markup`; `AgentContext.citation_scorer` (None when the retriever has no reranker or in tests); setting `cite_weak_below`.
**Tests:** a hypothesis property that streaming in *any* chunking equals sanitizing the whole text, a list of attack strings (split across chunks, nested badges, reference style, HTML, uppercase `<IMG`, `javascript:` and `data:` links, very long alt text), the node tests, the graph tests (both branches), the refusal detector, `eval abstention` with a fake graph.
**Live checks (proto profile, GPU gate):** one real question that cites, one the corpus cannot answer, a CSV reply containing an image; then the 100-question abstention run (about 5 to 10 minutes).
**Not decided here / told:** whether a weak-citation flag helps users (unmeasured); the threshold -3.0 is a guess from the scale seen in S2.6 (answerable best scores had a median of 1 to 4, unrelated passages scored below -4); abstention accuracy on the target model `gemma4:12b` is not measured by this run.
