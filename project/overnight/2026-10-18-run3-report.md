### S2.6 outline (written before building; 2026-10-18)
**What the rungs are in code** (cumulative, embedder `nomic-embed-text`, every rung returns the top 10 *chunks*, cut to documents by first occurrence = max score; the number of distinct documents per query is reported, because chunk size changes it):

| Rung | Index variant | Retriever |
|---|---|---|
| R0 | legacy chunks (v1: 800 characters, overlap 80, LangChain `RecursiveCharacterTextSplitter`), no prefix, no header, Chroma **L2** | v1 replica: 5 template queries, top 3 each, dedupe, re-sort by cosine of freshly embedded chunk text (`evals/legacy.py`) |
| R1 | same, **cosine** space | same |
| R2 | same | single query, dense only |
| R3 | legacy chunks + prefixes | dense |
| R4 | v2 chunks (512/64 tokens, section-aware), prefixes, no header | dense |
| R5 | v2 + header | dense |
| R6 | v2 + header | hybrid (RRF k=60, 50 candidates a side) |
| R7 | v2 + header | hybrid + rerank (MiniLM, default depth 10) |
| LOO | −BM25: v2+header, dense then rerank; −rerank = R6; −header: R7 on the v2 no-header index | |

Four index variants per dataset (`legacy-raw` as L2 and as cosine, `legacy-prefixed`, `v2-prefixed`, `v2-header`); one shared embedding cache per embedder, so R0 and R1 embed once. Indexes are built from loaded documents (BEIR: title + text; golden: the project's own loaders), not from files, into **scratch** folders (`scratch/ablation/...`): the user's `data/` is never touched.

**Datasets:** BEIR SciFact and NFCorpus test queries (headline), their tuning splits (SciFact train, NFCorpus dev; capped by a seeded sample) for the sweeps, the golden set (retrieval items: single-hop, multi-hop; multi-turn on the cached rewrite of D-076) split dev/test by D-065. Statistics: Δ, paired bootstrap 95% CI (10,000), and for the Holm family only (R7 vs R0 on SciFact nDCG@10, NFCorpus nDCG@10, golden test Recall@5) the permutation p, Holm-adjusted. Everything else descriptive (Δ and CI, no p, no verdict).

**Also built:** rerank-depth and fusion-candidates sweep on the tuning splits (scores cached per query/passage so the grid reruns cost nothing extra); `retrieval/calibrate.py` (✍️: abstain-threshold F1 sweep on golden dev, interval by bootstrap, check on golden test); embedder bake-off (`nomic-embed-text`, `qwen3-embedding:0.6b`, `embeddinggemma`: quality, query ms, ingest chunks/s) and reranker bake-off (MiniLM-L-6, `bge-reranker-base`); report writer; CPU gate (`PowerShell` load snapshot before/after every timed section, recorded in the results).
