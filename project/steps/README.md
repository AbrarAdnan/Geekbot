# Step logs

One file per step: `<step-id>-<slug>.md` (e.g. `S0.1-skeleton.md`), created from [`_TEMPLATE.md`](_TEMPLATE.md) at the end of each step. Each log records:
- the approved design
- the files changed
- the commands the user ran and their results
- the walkthrough Q&A
- decisions and open issues
- the handoff to the next chat

The overall tracker is [`../STATUS.md`](../STATUS.md).
