## Goal
Three guards at the end of the answer path (PLAN.md §7, §8.1 G3, §11 row S3.5 as changed by rev 20): the model's reply is **checked for a refusal**, its **citations are scored for fit**, and what reaches the screen is **cleaned of images and outside links**, on a chat reply and on a CSV reply alike.

A little context. The plan wanted a score threshold for abstaining; S2.6 measured it weak (D-080), and the user chose option B (D-082): trust the model's own "I could not find it in the documents", recognise it in code, and *measure* how often that works instead of assuming. The cleaning is the other half of the same worry as the citation check: a document can contain text that a model copies, and a markdown image in a reply is fetched by the browser the moment it is drawn, so a hostile document can make the user's browser send what the model knows to anyone, without a click. The system prompt asks the model not to write images; this step makes it not matter.

## Approved design (D-082, D-083; PLAN rev 20)
- **Abstention (option B).** The system prompt now tells the model to answer with exactly one sentence when the sources do not hold the answer (`I could not find it in the documents.`) and to cite nothing. `agent/citations.py::is_refusal` recognises that opening (and a few close wordings); `validate_citations` sets `abstained` = a reply that starts like a refusal *and* cites no source (a refusal that still cites is a partial answer). The "nothing found" stop-gap sentence counts too. No score gate anywhere; the calibrated threshold stays as data (`evals/results/s26-run1/abstain.json`).
- **`cite_check`.** After the stream, each sentence that carries `[n]` marks is scored against each cited source's text by the reranker's cross-encoder (the same object, shared through `retrieval.factory.citation_scorer_of`); a score under `Settings.cite_weak_below` (-3.0, **an unmeasured guess**) marks the citation weak. It only reports (`citation_checks`); it never changes the answer and never fails a turn (a scorer error is recorded in `citation_check_error`). Skipped when the retriever has no reranker.
- **`sanitize` (G3), the ✍️ piece.** `agent/sanitize.py`: `sanitize_text` and `StreamSanitizer`. Images (inline, reference, bare `![x]` made literal, HTML `<img>` and the tags that load things) are removed; a link to an address not found in the sources shown to the model becomes its text (only plainly relative links are kept without that test; `&#104;ttp://`, `javascript:`, `//host`, backslash paths count as outside); link-reference definitions to such addresses are dropped; autolinks likewise. It is **streaming-safe**: a small parser holds back only what may still become one of these, so a `![al` / `t](http://evil)` split across pieces cannot get through, and the property that matters is tested: **any cutting of the text into pieces gives exactly the same output as cleaning it whole**. A construct left open past 4,096 characters has its opener escaped. Removing markup can bring two pieces of text together into a new opener (`!` + `[`, `<` + `img`): one space is put between them.
- **Wiring.** `generate` streams through `StreamSanitizer` (events carry cleaned text; reasoning too); graph `generate → validate_citations → cite_check → sanitize → remember` and `csv_ask → sanitize → remember`; the one-off `geekbot csv ask` (which bypasses the graph) cleans its reply itself. State gained `abstained`, `citation_checks`, `citation_check_error`, `removed_markup`; the terminal shows "declined", weak citations and what was removed.
- **Measuring abstention.** `geekbot eval abstention` puts the 85 single-hop, multi-hop and unanswerable golden questions (not the multi-turn ones) to the real graph and counts correct refusals, wrong answers and wrong refusals, and, per answer, whether the citation check flagged it (`evals/abstention.py`).

Changes made during the build, and why: images with no destination (`![alt]`) are made literal instead of removed, because removing them would eat the `[1]` of "great![1]"; unterminated `![` is escaped instead of left as it is; the definition-line rule looks only at the first word (so a sentence that starts `[1]: the first source...` is left alone); `_destination` treats whatever follows an address that is not a quoted title as part of the address (`java<tab>script:` is outside). All four were found by the property tests or the attack list.

## Measured (proto profile: `gemma3:4b`, golden v0, Claude-authored and provisional; **not the target model**)
- **Abstention by refusal, option B:** of the 20 unanswerable questions, **8 were refused and 12 were answered** (dev 3 / 5, test 5 / 7); of the 65 answerable ones, **1 was refused wrongly** (S-025). **All 12 wrong answers cite a source** (for example "The studio's revenue last year was £17,258 [4]"): the small model invents an answer and attaches a citation. Run twice, the same numbers.
- **The citation relevance check** (limit -3.0) flagged **3 of the 12** wrong answers and **15 of the 64** good ones: as set it is not a useful second signal.
- For scale (D-080, other signal, same question set): the reranker-score threshold caught 7 of 8 dev and 6 of 12 test unanswerable questions but withheld 19 of 32 answerable dev questions and 13 of 48 test ones. Option B refuses almost nothing it should answer and misses most of what it should refuse (on this model).
- Time per question (retrieval with the rerank, generation, checks) median 0.84 s on `gemma3:4b`, warm.
- **Not measured:** the target model `gemma4:12b` (it may refuse far more reliably), multi-turn follow-ups, any other prompt wording.

## Review + walkthrough Q&A
Spots to review, most important first:
1. `agent/sanitize.py`: is "only plainly relative links are kept" the right strictness? (A relative link such as `[x](notes.md)` stays; anything with a colon, `&`, a backslash or `//` is outside.) Bare URLs in running text are left alone (not neutralised): a renderer that links bare addresses makes them clickable.
2. D-086: option B is built and measured; on the small model it lets 12 of 20 unanswerable questions through, each with a citation. Whether that is acceptable for the prototype, and what to try next, is the user's call (see below).
3. `cite_check`'s default limit (-3.0) is a guess and the first measurement says it is noisy; it only reports, so it is safe to leave, but the "weak citation" line may be noise.
