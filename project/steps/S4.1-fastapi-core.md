## Goal
The API server that owns the storage (PLAN.md §6.2, §6.3, §11 row S4.1): a FastAPI app whose start-up takes the storage lock, health routes, the knowledge-base routes (list, ingest, delete) and a job queue for long storage work, plus `geekbot serve`. A little context: a web server is one event loop; one blocking call (a SQLite write, a Chroma query, parsing a PDF) freezes every request for as long as it takes. So everything blocking goes to a worker thread, long writes go through a one-at-a-time queue, and a **heartbeat test** proves the loop stays free.

## Approved design (D-087)
- `server/app.py`: `create_app(settings, open_workspace=None)`. The lifespan opens the `Workspace` in a worker thread (this takes the storage lock first, so a second server fails at start-up and never listens), starts the job queue, and on shutdown stops the queue and closes the workspace. `HOST = "127.0.0.1"` is a constant.
- `server/jobs.py`: `JobQueue`, one worker task, bounded (16 waiting, then HTTP 429), each job's blocking work in `anyio.to_thread`; a raising job is a failed job, the worker lives on; finished jobs are kept in memory (last 100).
- `server/routes.py`: `GET /healthz` (touches nothing), `GET /v1/health` (document counts by state, chunks, vectors, embedder, active jobs), `GET /v1/kb/documents[?state=]`, `POST /v1/kb/ingest` (202 + job; body `paths`, `workers`), `DELETE /v1/kb/documents/{doc_id}` (202 + job), `GET /v1/jobs`, `GET /v1/jobs/{id}`.
- `server/schemas.py`: wire models (`extra="forbid"` on the request).
- `geekbot serve [--port N]` (no `--host`, no `--workers`); `Settings.server_port` (8000).
- Dependencies: `fastapi`, `uvicorn` in `pyproject.toml`.

Left for later, on purpose: threads and streamed answers (S4.2); the path allowlist, upload limits and the API key (S4.3: **until then the ingest route accepts any path that exists on this PC**, safe only because the server listens on 127.0.0.1); CSV routes (C5). The graph's context (chat model, retriever) is not built at start-up: S4.2 does it, with the model swap.
