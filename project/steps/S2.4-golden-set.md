## Goal
The ruler for "does Geekbot find the right documents on our documents": a file format for the ~100 hand-written golden questions, checks that keep a hand-made file honest, the development/test split D-065 asks for, the judgements (`qrels`) the metrics of S2.5 score against, a drafter that makes writing the questions faster, and loaders for the two public BEIR sets (PLAN.md §9, §11 row S2.4).

A little context. A retrieval score is only as good as its answer key. The key here is made by one person over several sittings, so the worst failures are quiet ones: a question pointing at a file that was renamed, a document ID that no longer matches because the repository moved (IDs are hashes of absolute paths, D-054), a question copied from the document's own sentence (which makes the search look better than it is), a split that quietly changes when an item is added. Most of this step is about making those loud.

- **Corpus:** 15 original documents about a fictional 12-person design studio, "Brightwater Studio", and its AI assistant "Lantern", in every format the loaders read, under `evals/corpus/{policy,project,ops,staff,analysis}/`. Facts recur across files on purpose (overlap for multi-hop questions) and a few look-alike facts are distractors; nothing contradicts anything else. Ten files are plain text-format files written directly. Four are generated by `evals/corpus_src/build_office_files.py` (two Word files, one PowerPoint, one Excel); the vendor memo's PDF is the Word export of `evals/corpus_src/vendor-memo.docx`, made by hand.

A single-hop item lists one source (chosen for facts stated in one place where possible); a multi-hop item lists every file that states a fact the answer needs. The unanswerable ones are near-topic: each was checked against the documents by reading them.
- **Tests:** `tests/unit/test_golden_corpus.py` builds the office files again, loads all 15 documents through the real loaders, and checks every question: sources exist, the validator finds nothing, every must-include phrase occurs in its sources, every source of a multi-hop question contributes one, every document is used, every item is flagged, and no question copies seven or more words in a row from its source. Two tests that already existed (`test_golden_md.py`, `test_eval_cli.py`) pointed at the blank template and now use the filled file or an inline blank one.
