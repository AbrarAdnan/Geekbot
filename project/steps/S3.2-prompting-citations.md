## Goal
Make the prompt something that can be tested and defended, and stop the model's citations from pointing at nothing (PLAN.md §7, §8.1, §8.2, §11 row S3.2). S3.1 gave a prompt as a Python string, sources in plain fences, and no check on the `[n]` marks the model writes.

A little context. A small model cites badly: `[7]` when three sources were shown, `[0]`, `[1, 2]`. A citation that points nowhere looks like support and checks out against nothing, so the application, not the model, decides what counts. The second idea is data-marking. A document is untrusted text that can say "ignore your instructions". If the boundary of a source is a fence line (`>>>`), a document can write a fence line. If the boundary is a mark at the start of *every* line, there is no line the document can write that is not inside the quote. The gotcha is the invisible line breaks: `splitlines` also splits on U+0085, U+2028 and a few control characters, and a document that uses one of them as a line break would otherwise slip a line past the mark.

## Approved design
Outline given in the chat of 2026-10-17 ("Start 3.2"); built straight after, without a separate go. Decisions: D-070. No plan change.

- `agent/prompts/system.md`: the instructions as a file. `packing.load_prompt` reads it once (`importlib.resources`); `SYSTEM_PROMPT` is that text.
- `agent/packing.py` (extended): `DATAMARK` (`"> "`), `datamark`, `source_label`, `source_header`, `source_block` (header, then the marked text), `check_question` and `QuestionError` (empty, or over `MAX_QUESTION_TOKENS` = 1000), and `PackedPrompt.labels`.
- `domain.py`: `Label` (the five labels of §8.2), `TAINTED_LABELS`, `is_tainted`.
- **`agent/citations.py` (the ✍️ piece):** `check_citations(answer, used) -> CitationCheck(text, cited, dropped)`.
- `agent/nodes.py`: `validate_citations` (new node), `section_trail` (drops a first heading equal to the title), `label_names`; `generate` and `no_context` now return `answer_labels`, and `no_context` also `cited` and `dropped_citations`.
- `agent/graph.py`: `generate → validate_citations → END`; `no_context → END`.
- `agent/state.py`: new keys `raw_answer`, `cited`, `dropped_citations`, `answer_labels` (all plain data).
- `agent/render.py`: "Sources cited:" / "Read, not cited:" (or "Read, but the answer cites none:"), a "removed from the answer" line, a "labels:" line.
- `cli.py`: `ask` refuses an empty or too long question before it loads any model.

**What changed from S3.1's layout:** the fences `<<<` / `>>>` are gone (the mark replaces them); the source header no longer repeats the title; the "Sources:" heading became "Sources cited:".

## Open issues / follow-ups
- **Settled by the runs:** `gemma3:4b` cites in the `[n]` form with the new prompt and abstains without citing; the checks are clean. **Still unverified:** `gemma4:12b` (target profile); whether the prompt without fences is as good as with them (no comparison was made, only three answers look normal); the removal path of `check_citations` on real model output (never triggered); the injection probe (optional, not run), and so whether the data-marking resists anything (S5.4 measures).
- **Ollama and an over-long prompt:** how Ollama cuts a prompt larger than `num_ctx` was not checked; the question cap keeps it from happening by our doing. Measure the real prompt size against `prompt_tokens` in the readings (the estimate is not an upper bound, D-064): `ask` shows `generation["prompt_tokens"]` only in the state today, not in the printout.
- **Wheel packaging:** `prompts/system.md` should ship in a wheel (hatchling includes non-Python files inside a listed package); not built here. An editable install, which the user has, finds it.
- **For S3.3:** the first-request cost after the warm-up and the cold-process rerank time (from the S3.1 log) are still open. The system prompt is now about 250 tokens and fixed, so prefix reuse can be measured there.
- **For S3.4:** the state gained four plain-data keys; the checkpointer will save them. `answer_labels` is per answer; per-message labels and `thread_taint` (§8.2) arrive with threads.
- **For S3.5:** links and images in the answer (`[1](url)` keeps its mark here), relevance of a cited source (`cite_check`), and dropping the sources when the model abstains (`ask` now lists them as "Read, but the answer cites none", which is honest but not yet an abstention).
- **Known gap by design:** no retry when the model forgets to cite or cites badly (a retry loop makes the cost unbounded); it is reported, and S5.2's judge measures how often it happens.
- **Privacy, still true:** `langsmith` came in with `langchain-core`; never set `LANGSMITH_*` / `LANGCHAIN_*` variables.
