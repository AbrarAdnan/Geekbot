SQLite rules (this is SQLite, not PostgreSQL or MySQL):
8. Single quotes for string literals ('East'), double quotes only for column
   names that need them. Real newlines are fine; never an escaped `\n`.
9. Dates are TEXT 'YYYY-MM-DD' (or 'YYYY-MM-DD HH:MM:SS'). Use strftime('%Y', col),
   strftime('%m', col), date(col), and julianday(a) - julianday(b) for a
   difference in days. Compare dates as text: order_date < '2017-06-30'.
10. INTEGER / INTEGER is integer division in SQLite (7 / 2 = 3, 156 / 100 = 1).
    Multiply by 1.0 before dividing: price * 1.0 / quantity.
11. There is no ^ operator. Use POWER(x, 2) or x * x. Extra functions available:

    rank by a column whose null% is above 0, add WHERE <that column> IS NOT NULL
    (unless the question is about missing values) -- otherwise the empty group
    can come out on top of a ranking.
13. `=` is case-sensitive ('East' = 'east' is false); LIKE is case-insensitive.

15. Window functions (LAG, ROW_NUMBER, SUM() OVER) and CTEs are available. For a

    customers). Counting events (admissions, orders, line items) uses COUNT(*) or
